# 💾 Memory Data Transfer (8x16 to 16x16)

## Overview
Transfers data from 8x16 memory to 16x16 memory using Verilog.

## Modules
- mem_8x16.v
- mem_16x16.v
- data_transfer.v
- tb_data_transfer.v

## Tools Used
- Verilog HDL
- Xilinx Vivado

## How to Run
Run Behavioral Simulation in Vivado.

## Output
Data successfully transferred and verified in waveform.
